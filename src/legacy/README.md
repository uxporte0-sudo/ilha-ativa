# Legacy Boundary

LEGACY - DO NOT USE in official MVP flows.

Legacy pages and components may still live in their original locations during hardening to avoid accidental runtime changes. They must not be imported by official routes, product components, domain services, or the Official Data Layer.

Replaced by official domain:

- `Court` -> `Local`
- `Booking` -> `Participacao`
- `RepairRequest` -> `Zeladoria`
- `EventLobby` -> future social resource outside the MVP domain
- `Atividade` -> `Ativo`
